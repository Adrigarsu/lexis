# ADR-001 · React + TypeScript + Vite

- **Estado:** Aceptado
- **Fecha:** 2026-11-08
- **Registro:** D-05

- **Contexto:** una PWA con mucha interacción (tarjetas, escritura a mano, audio) y una sola desarrolladora que aprende.
- **Decisión:** React 19 con TypeScript en modo estricto y Vite como herramienta de compilación (versiones en ADR-020).
- **Consecuencias:** el ecosistema más grande y mejor documentado; TypeScript detecta errores antes de ejecutar. Se acepta un paquete inicial algo mayor que con Svelte o Preact.
