# ADR-004 · FSRS para el repaso

- **Estado:** Aceptado
- **Fecha:** 2026-11-08
- **Registro:** D-06

- **Contexto:** el repaso espaciado decide qué tarjeta toca y cuándo.
- **Decisión:** el algoritmo FSRS con la librería ts-fsrs, en el dispositivo.
- **Consecuencias:** menos repasos que SM-2 para el mismo recuerdo y funciona sin red. La dificultad adaptativa (D-110) va aparte, en su propio campo de práctica.
