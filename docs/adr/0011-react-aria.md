# ADR-011 · React Aria

- **Estado:** Aceptado
- **Fecha:** 2026-11-10
- **Registro:** D-118

- **Contexto:** WCAG 2.2 AA en diálogos, menús, pestañas y botones de valoración.
- **Decisión:** React Aria Components, sin estilos propios, vestidos con Tailwind.
- **Consecuencias:** teclado, foco y lectores de pantalla resueltos por Adobe. Se aprende su API de estados (`data-focused`, `data-pressed`).
