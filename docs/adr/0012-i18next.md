# ADR-012 · i18next

- **Estado:** Aceptado
- **Fecha:** 2026-11-10
- **Registro:** D-119

- **Contexto:** la interfaz es en español, pero no se quieren textos escritos dentro del código.
- **Decisión:** i18next con react-i18next; un fichero JSON por idioma, empezando por `es`.
- **Consecuencias:** añadir otro idioma es añadir un fichero. Plurales y fechas se formatean con `Intl`.
