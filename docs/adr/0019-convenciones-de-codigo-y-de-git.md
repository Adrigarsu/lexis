# ADR-019 · Convenciones de código y de Git

- **Estado:** Aceptado
- **Fecha:** 2026-11-12
- **Registro:** D-131

- **Contexto:** el código es público y de portfolio, y debe seguir estándares globales (D-75).
- **Decisión:** el código, los nombres y los comentarios van en inglés; la interfaz, en español con i18next; la documentación, en español. Las rutas, en español (D-129).
- **Consecuencias:** cualquier desarrollador puede leer el código, y el usuario ve todo en español.
