# Casilla

Una afirmación que el usuario confirma: edad y privacidad al registrarse. Para activar o desactivar una función, usa el Interruptor.

`<label class="lx-check">` con un `<input type="checkbox">` y el texto dentro, así se puede pulsar toda la fila (44px de alto). Marcada en `jade`, con check `on-jade`. Con error, `aria-invalid="true"` y el mensaje `lx-field__error` enlazado.

- Sí: textos en primera persona («Tengo 14 años o más»).
- No: casillas premarcadas para consentimientos.
