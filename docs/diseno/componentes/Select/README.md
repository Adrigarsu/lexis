# Select

Elegir una opción de una lista corta y cerrada que no hace falta ver entera: fuente, guía de escritura, tema, día del resumen semanal.

Usa el `<select>` nativo con la clase `lx-select`, dentro de un `lx-field` con su etiqueta. En el móvil abre el selector del sistema, que es accesible y cómodo.

## Cuándo no

- Con 2 o 3 opciones que conviene ver a la vez, usa Segmentos.
- Para un número, usa el Spinner.
- Para activar o desactivar algo, usa el Interruptor.
