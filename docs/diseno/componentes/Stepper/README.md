# Spinner

Ajustar un número pequeño con − y +: las metas (minutos al día de 5 en 5 entre 5 y 120, palabras nuevas de 0 a 30, días de descanso de 0 a 3). Decisión D-100.

`<div class="lx-stepper" role="group" aria-labelledby="…">` con dos botones (con `aria-label` que dice qué cambian) y un `<output aria-live="polite">` en medio con el valor y su unidad. Cada botón mide 44 × 44px. En el límite, el botón correspondiente se desactiva.

- Sí: dentro de una fila de lista agrupada, con la etiqueta a la izquierda.
- No: para números grandes o libres. Ahí va un Campo de texto con `inputmode="numeric"`.
