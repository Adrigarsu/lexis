# Interruptor

Activa o desactiva un ajuste que se aplica al momento, sin botón de guardar: colores de tono, audio automático, valoración automática, azul bolígrafo, recordatorios.

`<label class="lx-switch">` con el texto (`lx-switch__title` y, si hace falta, `lx-switch__desc`) y un `<input type="checkbox" role="switch">`. Activo: pista `jade-bright` y botón `surface`. Apagado: pista `surface-sunken` con borde `line-strong` (3:1).

- Sí: un título corto y una descripción de una línea con el efecto o el motivo.
- No: usarlo para algo que necesita confirmación. Para eso, un botón.
- Desactivado: explica en la descripción por qué.
