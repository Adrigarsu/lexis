# Pantallas

Exportadas del lienzo «Lexis · Wireframes y diseño» (página *Diseño en color*) el 12 de noviembre de 2026. Cada pantalla tiene su **PNG** (cómo se ve) y su **HTML** (estructura, textos y estilos con los tokens de `assets/lexis.css`). El PNG muestra el estado inicial; abre el HTML en el navegador para ver las hojas, diálogos y opciones que se abren con un botón.

- El diseño se implementa con los componentes y tokens de [sistema-diseno.md](../sistema-diseno.md), no copiando el HTML.
- Qué pantalla lleva a cuál: [flujo-pantallas.md](../flujo-pantallas.md). Rutas: [rutas.md](../../arquitectura/rutas.md).
- Si una historia necesita una pantalla que no está aquí, es un hueco: se plantea en el plan con opciones.
