# EP-03 · Escritura de caracteres

## HU-18 · Escribir un carácter trazo a trazo

Must · RF-24, RF-26, RF-82

Como estudiante, quiero escribir caracteres con el dedo o el ratón y que se me corrija cada trazo, para aprender a escribirlos bien.

- Dado que hago un trazo correcto, cuando lo termino, entonces queda fijado y paso al siguiente.
- Dado que hago un trazo con forma, dirección u orden incorrectos, cuando lo termino, entonces se marca el error y puedo repetirlo.
- Dado que pulso "Pista", cuando se muestra, entonces se resalta solo el inicio y la dirección del siguiente trazo y, con la valoración automática, la nota será "Otra vez".
- Dado que termino el carácter, cuando aparece la valoración, entonces la elijo yo con los 4 botones; si tengo activada la valoración automática, se aplica la tabla 3.2.1 y puedo corregirla (HU-14).
- Dado que tengo activado "Escribir en azul bolígrafo" (por defecto), cuando trazo, entonces mis trazos se ven en azul; si lo apago, se ven en tinta.

## HU-19 · Elegir cómo me guía la escritura

Must · RF-25

Como estudiante, quiero elegir si escribo sin guía, sobre el contorno o viendo el siguiente trazo, para ajustar la dificultad.

- Dado que elijo un modo de guía, cuando cierro la app y vuelvo otro día, entonces sigue el mismo modo.
- Dado que estoy escribiendo, cuando cambio el modo, entonces se aplica en ese mismo carácter.

## HU-20 · Practicar caracteres y palabras por separado

Must · RF-22, RF-23

Como estudiante, quiero practicar la escritura de cada carácter y también de palabras completas, para dominar los caracteres que se repiten y las palabras difíciles.

- Dado que se activa la escritura de 你好, cuando reviso mis prácticas, entonces tengo una de escritura para la palabra y otra para cada carácter que aún no tenía (你 y 好).
- Dado que 你 ya estaba activo por otra palabra, cuando se activa 你好, entonces no se duplica la práctica de 你.

## HU-21 · Ver cómo se forma un carácter

Must · RF-27, RF-28

Como estudiante, quiero ver la animación de trazos, el radical y los componentes, para memorizar el carácter por sus partes.

- Dado que abro la ficha de un carácter, cuando pulso "Ver trazos", entonces se anima el orden de trazos y puedo repetirlo.
- Dado que miro la ficha, cuando consulto sus partes, entonces veo el radical y los componentes con su significado.

## HU-22 · Estudiar caracteres comunes extra

Should · RF-29

Como estudiante, quiero aprender radicales y caracteres frecuentes fuera del HSK 1, para leer más cosas reales.

- Dado que activo el conjunto extra en ajustes, cuando empiezo la siguiente sesión, entonces sus caracteres entran como nuevos con las tres prácticas.
- Dado que lo desactivo, cuando empiezo una sesión, entonces dejan de aparecer, pero se conserva su progreso.

## HU-70 · Aprender los componentes de los caracteres

Should · RF-86

Como estudiante, quiero aprender y escribir las piezas que forman los caracteres del HSK 1, para entender cómo se construyen y recordarlos mejor.

- Dado que va a entrar un carácter nuevo que contiene un componente que aún no he visto, cuando se planifica la sesión, entonces ese componente entra antes, con su ficha.
- Dado que practico la escritura de un componente, cuando lo trazo, entonces se corrige trazo a trazo igual que un carácter (HU-18).
- Dado que un componente no se usa como carácter suelto (por ejemplo 亻), cuando se programan sus prácticas, entonces solo tiene significado y escritura.
- Dado que desactivo el conjunto en ajustes, cuando empiezo una sesión, entonces sus componentes dejan de aparecer, pero se conserva su progreso.

## HU-23 · Practicar escritura sin poder trazar

Must · RNF-22

Como estudiante que usa lector de pantalla o teclado, quiero una alternativa al trazado, para practicar la escritura igualmente.

- Dado que uso VoiceOver o teclado, cuando llega una tarjeta de escritura, entonces puedo elegir el carácter correcto entre varios parecidos.
